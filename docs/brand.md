# VedaOps brand notes

The brand connects a heartbeat monitor with a healing neem leaf. The voice stays calm and specific: say what happened, what action was taken, and what the result was.

## Identity

- Name: **VedaOps**, with `Veda` bold and `Ops` lighter in the leaf color.
- Tagline: **වේද · the vedamahaththaya for your servers**.
- Short line: **Diagnose. Heal. Tell you.**
- Mark: heartbeat line ending in a turmeric neem leaf. Keep clear space around the mark and do not render it below 24 px.

## Colors

| Name | Hex | Use |
|---|---|---|
| Neem | `#0E2F26` | Primary dark surface and wordmark |
| Leaf | `#2F8F5B` | Healthy state and `Ops` wordmark |
| Turmeric | `#E0A100` | Warning state |
| Mist | `#E9EFEA` | Light surface and mark line |
| Chili | `#C8452B` | Critical state only |

## Type and incident wording

- Bricolage Grotesque for headings and the wordmark.
- JetBrains Mono for commands, logs, dashboards, and incident fields.
- Noto Sans Sinhala only for the small Sinhala tagline.
- Use the same action values everywhere: `restart`, `ignore`, `notify_human`.
- Keep incident messages in this order: alert, cause, action, result. Do not use jokes or alarming language during incidents.
